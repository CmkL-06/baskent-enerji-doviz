# MoneyTransferTurkey (Legacy) — Dokümantasyon

Bu klasör legacy proje dokümantasyonu ve görselleştirme dosyalarını içerir.

## İçindekiler

| Dosya | Açıklama | Nasıl kullanılır |
|-------|----------|------------------|
| **system-overview.html** | Tüm katmanların ve bileşenlerin görsel özeti (API, Business, Data, Entity, veritabanı) | Tarayıcıda açın (çift tıklama veya sürükle-bırak) |
| **SYSTEM-ARCHITECTURE.md** | Sistem mimarisi: katmanlı yapı, modüller, veri akışı, proje referansları | VS Code / GitHub’da Markdown önizleme veya Mermaid destekli editör |
| **frontend-preview.html** | Frontend ekranlarının statik önizlemesi (hangi sayfa hangi API’ye karşılık gelir) | Tarayıcıda açın |
| **README.md** | Bu indeks | — |

## Hızlı bağlantılar

- **Mimariyi görmek:** `system-overview.html` veya `SYSTEM-ARCHITECTURE.md`
- **Frontend’in nasıl görüneceğini görmek:** `frontend-preview.html`
- **Frontend projesini çalıştırmak:** Ana dizindeki [frontend/README.md](../frontend/README.md) ve `npm run dev`

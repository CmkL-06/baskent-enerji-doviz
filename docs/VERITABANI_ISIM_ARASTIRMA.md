# Veritabanı isim araştırması (arşiv)

**Tarih:** 2026-02-24

Plesk ve yerel ayarlarda yapılan araştırma sonucu **gerçek veritabanı adı** tespit edildi: **mtt-moneyexchangeturkey** (SQL Server sys.databases ile doğrulandı).

**Güncel tek referans:** Tüm bağlantı ve veritabanı bilgileri artık **REFERANS_VERITABANI_VE_YAPILANDIRMA.md** dosyasında toplanmıştır. Eski/boş isim (mtturkey_exchange veritabanı adı olarak) kaldırıldı; proje ve dokümanlar **mtt-moneyexchangeturkey** ile güncellendi.
